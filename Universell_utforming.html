Del 1: Hva menes med universell utforming?

Universell utforming kan være å utvikle noe som for eksempel en bygning eller et produkt som kan brukes som mange som mulig, uavhengig av alder eller funskjonsevne, uten å måtte ordne spesielle tilpassinger.
WCAG står for Web Content Accessibility Guidelines, WCAG var utviklet av W3C for å gjøre nettsider og digitale produkter tilgjengelig for alle.
